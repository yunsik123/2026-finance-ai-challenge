# 먹투 OCR 테스트용 합성 문서

모든 문서는 테스트 전용이며 실제 기관에서 발급된 서류가 아닙니다. 모든 인물·상호·번호·주소·금액은 가상이고, 이미지마다 `TEST ONLY · 법적 효력 없음` 워터마크가 있습니다.

## 포함 파일

- 01: 사업자등록증 — 깨끗한 원본형/휴대폰 촬영형
- 02: 일반음식점 영업신고증 — 깨끗한 원본형/휴대폰 촬영형
- 03: 부가가치세 과세표준증명 — 깨끗한 원본형/스캔형
- 04: POS 월별 매출 집계
- 05: 카드·VAN 정산 내역
- 06: 사업용 계좌 거래내역 — 깨끗한 원본형/휴대폰 촬영형
- 07: 배달 플랫폼 정산 내역
- 08: 기존 대출·상환 현황
- 09: 상가 임대차계약서 요약본
- 10: 급여대장
- 11: 투자금 사용계획서
- 12: 사업체 소유구조 확인서
- ground_truth.json: OCR 결과 대조용 핵심 정답 데이터

실제 공공기관·은행·POS·배달앱 양식은 제공처마다 다르므로, 이 묶음은 업로드·OCR·필드 매핑·교차검증 로직을 먼저 검증하기 위한 것입니다.
